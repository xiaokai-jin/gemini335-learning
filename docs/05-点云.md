# 阶段五：点云

## 目标

通过 ROS2 获取 Gemini 335 点云，理解点云消息、坐标系和点云类型，并使用 RViz2 查看点云。

本阶段暂不实现地面过滤和噪声点过滤，先完成点云获取、查看、保存和基础参数验证。

## 1. 点云是什么

深度图中的每个有效像素都可以根据相机内参转换为空间点：

```text
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
Z = depth(u, v)
```

其中 `fx`、`fy`、`cx`、`cy` 是深度相机内参，`X`、`Y`、`Z` 是相机坐标系中的三维坐标。大量三维点组合起来就是点云，ROS2 使用 `sensor_msgs/msg/PointCloud2` 传输点云。

## 2. 启动点云

每个新终端先加载工作空间：

```bash
source /opt/ros/humble/setup.bash
source /home/xiaokai/orbbec_ws/install/setup.bash
source /home/xiaokai/gemini335-learning/ros2/install/setup.bash
```

启动相机：

```bash
ros2 launch gemini335_bringup gemini335.launch.py
```

当前 launch 文件的点云默认值以
[gemini335.launch.py](../ros2/gemini335_bringup/launch/gemini335.launch.py) 为准：

```text
普通深度点云：开启
彩色点云：开启
点云降采样：4
对齐模式：SW
```

彩色点云需要彩色流和深度流同时开启。当前 Gemini 335 使用软件对齐，避免不支持硬件 D2C profile 时启动失败。

## 3. 点云话题

普通深度点云：

```text
/gemini335/depth/points
```

彩色点云：

```text
/gemini335/depth_registered/points
```

查看话题类型、发布者和频率：

```bash
ros2 topic info /gemini335/depth_registered/points
ros2 topic hz /gemini335/depth_registered/points
```

查看一条消息：

```bash
ros2 topic echo /gemini335/depth_registered/points --once
```

常见字段包括 `x`、`y`、`z` 以及颜色字段。具体字段以当前驱动发布的 `PointCloud2` 消息为准。

## 4. 使用 RViz2 查看

启动 RViz2：

```bash
rviz2
```

在 RViz2 中：

1. 将 `Fixed Frame` 设置为点云消息的 `header.frame_id`；
2. 点击 `Add`，选择 `By topic`；
3. 选择 `/gemini335/depth_registered/points`；
4. 将 `Style` 设置为 `Points` 或 `Flat Squares`；
5. 根据点云密度调整 `Size (Pixels)`。

查看点云坐标系：

```bash
ros2 topic echo /gemini335/depth_registered/points --once
```

如果点云不显示，优先检查 `Fixed Frame` 是否存在：

```bash
ros2 topic list | grep points
ros2 run tf2_tools view_frames
```

实际 frame 名称应以消息中的 `header.frame_id` 和 TF 结果为准。

## 5. 普通点云和彩色点云

### 普通深度点云

```bash
ros2 launch gemini335_bringup gemini335.launch.py \
  enable_point_cloud:=true \
  enable_colored_point_cloud:=false
```

话题：

```text
/gemini335/depth/points
```

普通点云主要包含三维坐标，不需要 RGB 与深度对齐。

### 彩色点云

```bash
ros2 launch gemini335_bringup gemini335.launch.py \
  enable_point_cloud:=false \
  enable_colored_point_cloud:=true \
  depth_registration:=true \
  align_mode:=SW
```

话题：

```text
/gemini335/depth_registered/points
```

彩色点云会将深度点投影到彩色图像，为三维点附加颜色。它需要彩色流、深度流、相机标定参数和深度到彩色的对齐过程。

## 6. 点云参数

| 参数 | 当前默认值 | 作用 |
|---|---:|---|
| `enable_point_cloud` | `true` | 发布普通深度点云 |
| `enable_colored_point_cloud` | `true` | 发布彩色点云 |
| `point_cloud_decimation_filter_factor` | `4` | 点云降采样倍数，驱动支持 `1~8` |
| `point_cloud_qos` | `default` | 点云话题 QoS |
| `cloud_frame_id` | 空 | 覆盖点云消息坐标系 |
| `ordered_pc` | `false` | 是否保留点云与图像像素的二维排列关系 |
| `depth_registration` | `false` | 是否执行深度到彩色的注册 |
| `align_mode` | `SW` | 深度对齐方式，当前建议使用软件对齐 |

说明：虽然 `depth_registration` 的 launch 默认值是 `false`，但开启
`enable_colored_point_cloud` 后，Orbbec 驱动会自动启用深度到彩色的注册，以生成彩色点云。

降采样倍数越大，点数越少，显示和传输开销越低，但空间细节也会减少：

```bash
ros2 launch gemini335_bringup gemini335.launch.py \
  enable_colored_point_cloud:=true \
  depth_registration:=true \
  align_mode:=SW \
  point_cloud_decimation_filter_factor:=2
```

## 7. 保存点云

Orbbec 驱动提供保存点云服务。先查看服务：

```bash
ros2 service list | grep save
```

常见服务为：

```text
/gemini335/save_point_cloud
/gemini335/save_colored_point_cloud
```

调用服务：

```bash
ros2 service call /gemini335/save_point_cloud std_srvs/srv/Empty "{}"
```

保存彩色点云：

```bash
ros2 service call /gemini335/save_colored_point_cloud std_srvs/srv/Empty "{}"
```

实际保存位置和文件名以驱动终端日志为准。保存前应先确认对应点云话题已经发布。

也可以录制 ROS2 数据，后续再处理：

```bash
ros2 bag record /gemini335/depth_registered/points
```

停止录制时按 `Ctrl+C`。

## 8. 基础检查流程

```bash
ros2 node list
ros2 topic list | grep -E 'depth/points|depth_registered/points'
ros2 topic info /gemini335/depth_registered/points
ros2 topic hz /gemini335/depth_registered/points
ros2 topic echo /gemini335/depth_registered/points --once
```

如果彩色点云启动失败，检查：

- `enable_color` 和 `enable_depth` 是否为 `true`；
- 彩色点云是否开启；
- `align_mode` 是否为 `SW`；
- 彩色和深度分辨率是否为相机支持的组合；
- 日志中是否出现 `Current stream profile is not support hardware d2c process`。
