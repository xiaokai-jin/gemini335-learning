# 阶段一：环境安装

## 目标

完成 ROS 2、Orbbec 驱动和 Gemini 335 相机的连接，能够看到相机节点和图像话题。

## 环境

- Ubuntu
- ROS 2 Humble
- Orbbec Gemini 335
- Orbbec ROS 2 驱动

项目中的 bringup 包不包含相机驱动，驱动工作空间默认位于：

```text
/home/xiaokai/orbbec_ws
```

## 加载环境

每次打开新终端时执行：

```bash
source /opt/ros/humble/setup.bash
source /home/xiaokai/orbbec_ws/install/setup.bash
source /home/xiaokai/gemini335-learning/ros2/install/setup.bash
```

## 构建项目

修改 launch 文件后，在项目根目录执行：

```bash
cd /home/xiaokai/gemini335-learning
colcon build \
  --base-paths ros2 \
  --build-base ros2/build \
  --install-base ros2/install
source ros2/install/setup.bash
```

## 启动相机

```bash
ros2 launch gemini335_bringup gemini335.launch.py
```

如果连接多台相机，可以指定序列号：

```bash
ros2 launch gemini335_bringup gemini335.launch.py \
  serial_number:=CP0F463000XE
```

## 检查是否成功

在另一个终端加载环境后执行：

```bash
ros2 node list
ros2 topic list
```

应该可以看到相机节点和类似下面的话题：

```text
/gemini335/color/image_raw
/gemini335/depth/image_raw
/gemini335/depth/points
```
