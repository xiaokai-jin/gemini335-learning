# 阶段三：深度图

## 目标

获取深度图，理解每个像素代表的距离信息，并认识常见的深度数据问题。

## 深度话题

默认的深度图话题是：

```text
/gemini335/depth/image_raw
```

查看话题信息和发布频率：

```bash
ros2 topic info /gemini335/depth/image_raw
ros2 topic hz /gemini335/depth/image_raw
```

## 查看深度图

启动图像查看工具：

```bash
ros2 run rqt_image_view rqt_image_view
```

在窗口中选择：

```text
/gemini335/depth/image_raw
```

深度图通常不是普通的彩色照片。画面中的亮暗或颜色一般表示距离远近，具体显示效果取决于查看工具。

## 调整深度分辨率和帧率

```bash
ros2 launch gemini335_bringup gemini335.launch.py \
  depth_width:=1280 \
  depth_height:=800 \
  depth_fps:=30
```

阶段四默认同时开启左右目 IR 流，因此深度流必须与左右目使用相同的分辨率和帧率。Gemini 335 当前测试支持 `1280 x 800 @ 30 FPS` 的深度和左右目组合。如果只测试深度而不使用左右目，可以关闭左右目：

```bash
ros2 launch gemini335_bringup gemini335.launch.py \
  enable_left_ir:=false enable_right_ir:=false \
  depth_width:=1280 depth_height:=800 depth_fps:=30
```

## 深度噪声是什么

深度噪声是深度值在小范围内不稳定。例如相机和物体都没有移动，但同一个像素的距离读数仍然有轻微变化。

初步可以做：

- 连续读取多帧，对同一个位置取平均值；
- 使用中值滤波，去掉偶尔出现的异常值；
- 对深度图做可视化，观察噪声是否集中在边缘、反光物体或远距离区域。

这些处理的目标是让深度结果更稳定，并不是改变相机本身的测量能力。

## 深度空洞是什么

深度空洞是某些像素没有有效深度值，常见表现是黑色区域或数值为零。它可能出现在反光、透明、太暗、太远或纹理不足的物体上。

初步可以做：

- 统计一帧中无效深度像素的数量；
- 在显示时把无效区域标记出来；
- 使用邻近有效像素或多帧数据进行有限填补；
- 对填补后的结果保留标记，避免把估计值误认为真实测量值。

在这个阶段只需要先观察和识别噪声、空洞，后续再实现滤波和空洞填补算法。

## 当前阶段暂不测量距离

查询指定像素的深度可以帮助理解数据格式，但“测量相机到物体的距离”涉及目标选择、坐标系和误差评估，放到后面的三维测量阶段更合适。

## 小结

这一阶段重点是确认：

- 能够发布和查看深度图；
- 理解深度值与距离的关系；
- 能够区分噪声和空洞；
- 知道后续可以用滤波和填补方法改善数据。
