# Gemini 335 相机学习记录

## 1. 项目简介

本项目用于记录 Gemini 335 双目 RGB-D 相机的学习和实验过程，包括相机数据获取、深度图、点云、标定、目标检测和三维测量等内容。

当前阶段只学习和使用相机，暂不与 OpenArm 机械臂结合。

## 2. 学习目标

- 掌握 RGB 图像获取
- 掌握左右目图像获取
- 掌握深度图获取与显示
- 掌握点云获取与查看
- 理解双目视觉和 RGB-D 相机原理
- 完成相机内参标定
- 实现 RGB 与深度图像对齐
- 实现目标检测
- 实现物体距离和尺寸测量
- 学习相机在具身智能中的基本应用

## 4. 学习路线

### 阶段一：环境安装

- 安装 Gemini 335 SDK 或 ROS 2 驱动
- 连接相机并确认设备正常
- 查看相机固件和设备信息
- 运行官方示例程序

### 阶段二：RGB 图像

- 获取彩色图像
- 显示实时视频
- 保存图片和视频
- 调整分辨率和帧率
- 理解图像编码格式

### 阶段三：深度图

- 获取深度图
- 显示深度图
- 查询指定像素的深度
- 处理深度噪声和空洞
- 了解深度数据中的无效值和异常值

### 阶段四：双目图像

- 获取左目图像
- 获取右目图像
- 理解双目视差
- 了解深度计算原理
- 对比双目深度和 RGB-D 深度

### 阶段五：点云

- 获取点云数据
- 使用 RViz2、Open3D 或其他工具查看点云
- 保存和读取 PCD 文件
- 了解点云坐标系

### 阶段六：图像对齐

- RGB 图像与深度图对齐
- 理解彩色相机和深度相机内参
- 了解相机外参
- 将深度值映射到彩色图像
- 验证对齐误差

### 阶段七：相机标定

- 使用棋盘格进行标定
- 标定相机内参
- 标定畸变参数
- 标定 RGB-D 外参
- 评估标定误差

### 阶段八：目标检测

- 颜色分割
- 轮廓检测
- ArUco 标记识别
- AprilTag 识别
- YOLO 目标检测
- 多目标检测和跟踪

### 阶段九：三维测量

- 获取目标像素位置
- 查询目标深度
- 计算目标三维坐标
- 测量物体距离
- 测量物体宽度、高度和体积
- 比较不同距离下的测量误差
